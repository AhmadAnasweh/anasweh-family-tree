# منصة تراث عائلة العناسوة

واجهة عربية RTL، موجهة للهاتف أولًا، لاستعراض شجرة عائلة كبيرة وإدارتها دون كتابة JSON أو التعامل مع المفاتيح التقنية.

## الخصوصية والأمان

- لا توجد مفاتيح، كلمات مرور، أو بيانات تعريف شخصية في هذا المستودع.
- نموذج «طلب تعديل» لا يرسل البريد ولا يخزن الطلب؛ ينشئ رقم مرجع محليًا ويفتح تطبيق البريد برسالة معدّة مسبقًا.
- لا ترفع أو ترسل صور الهوية إلى الموقع أو GitHub. يمكن للمشرف طلبها لاحقًا عبر قناة خاصة عند الحاجة.
- بيانات العرض التجريبية محفوظة في `localStorage` في جهاز المتصفح فقط. يلزم ربط نسخة الإنتاج بواجهة خادم مصادَق عليها وقاعدة بيانات قبل إدخال بيانات عائلية حقيقية.

## نظاما التعريف

1. `id`: UUID داخلي ثابت ومفتاح البيانات الوحيد. لا يعتمد على الاسم أو ترتيب الأسرة ولا يتغير عند إعادة ترتيب الشجرة.
2. `lineageCode`: رمز بشري مقروء، مثل `A-1-2-4`. يُستخدم للبحث والإشارة في المحادثات، وقد يتغير عند تنظيم الفروع. **لا يستخدم أبدًا كمفتاح قاعدة بيانات.**

## البحث العربي

يطبّق البحث تطبيعًا لكتابة الألف (`أ/إ/آ/ا`) والياء والألف المقصورة والتاء المربوطة والهمزات والتشكيل والتطويل، ثم يدعم مطابقة كلمات جزئية وترتيبًا متسامحًا للحروف. تحفظ البيانات الاسم الأصلي كما كُتب؛ التطبيع للبحث فقط.

## الأداء

تُرسم فقط العقد الموجودة في الفروع المفتوحة بدل رسم الدليل كاملاً. من لوحة الإدارة استخدم «اختبار 1,200 شخص» لمحاكاة سجل كبير؛ تبدأ الفروع مطوية كي يبقى الرسم والتفاعل سريعَين على الهاتف.

## قبل تشغيل بيانات حقيقية

هذه واجهة static قابلة للنشر ولا تصلح وحدها كمنظومة سجلات حساسة متعددة المستخدمين. يلزم إضافة: تسجيل دخول وأدوار، API مع تحقق علاقات على الخادم، قاعدة بيانات، سجل تدقيق غير قابل للتعديل، نسخ احتياطي، وموافقة واضحة على سياسة الخصوصية.
